# Flotilla logo

Selected design: **Close quarters**, from the Fleet in blue exploration.

`logo.svg` is the original three-boat mark on a transparent 128 × 128 canvas. Primary blue: `#2359df`; secondary blue: `#7aa8fb`. Its paths and spacing match the selected candidate exactly. The asset is self-contained and has no font or external resource dependencies.
